My Projects

Academic projects that helped me apply programming concepts in practice.

1st Semester

HornRush

C Programming + Raylib

HornRush is a C-based car driving game developed using the Raylib library. The project helped me apply programming fundamentals through an interactive game.

Project Features
  • Multiple vehicle selection with 7 different cars
  • Road movement and lane switching
  • Enemy cars with different behaviors
  • Horn interaction with nearby enemy cars
  • Trees and houses as environment objects
  • Collision detection between cars
  • Distance and time-based gameplay
  • Background music and car horn sound
  • Sound ON/OFF settings
  • High-score save and load using file handling
  • Menu, Game, Game Over, Settings, Vehicle Select and Developers screens
Project Goal

The goal of HornRush was to develop a C-based academic project that helped me practice programming fundamentals and apply the concepts learned during my first semester.

Academic Game Development Project
2nd Semester

Industrial Engineering Management System

C++ + Object-Oriented Programming

A C++ and OOP-based academic system designed to manage production tasks, workstations and production line performance.

Project Features
  • Create and manage production tasks
  • Manual and Automated task types
  • Line ID and Production Name
  • Target Takt Time
  • Production Line Configuration
  • Workstation creation
  • Assign tasks to workstations
  • Total workstation workload
  • Identify bottleneck workstation
  • Total work content
  • Line efficiency
  • Balance delay
  • Line balancing report
  • Production line capacity
  • Save and load task data using files
Project Goal

The goal of this project was to develop a C++ and OOP-based system for managing production tasks, workstations, production line configuration, workload, bottleneck, line efficiency, balance delay and production capacity.
